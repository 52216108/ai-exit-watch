AI落地安全检测 · Windows 试用版 0.3.1

适用：Windows 11，Intel / AMD 64 位（x64）。
本包包含运行环境，无需安装 .NET。未做商业代码签名。
本版已在 macOS 上交叉构建并验证检测核心，Windows 实机界面、托盘通知、开机启动、休眠恢复和真实 Mihomo 命名管道尚待试用确认。

开始使用
1. 将整个压缩包解压到固定目录，不要直接在压缩包内运行。
2. 双击 AIExitWatch.exe（应用显示名称：AI落地安全检测）。
3. 保持你原有代理正常运行，等待第一轮检测完成。
4. 确认 Claude 网页、Claude API、ChatGPT 网页的出口符合预期，再点击“确认正常基准”。
5. 设置中可发送测试通知。关闭窗口后继续在右下角托盘运行，双击盾牌打开；右键盾牌可退出。
6. 如启用登录启动，移动或删除文件夹前先在设置中取消此项并保存。

未签名应用可能被 Windows SmartScreen 提醒。请先核对来源和随包 SHA-256；确认来源可信后，可按系统提供的“更多信息 → 仍要运行”操作。不要关闭系统安全防护。公司设备策略不允许时请联系管理员。

功能
• 60 / 120 / 300 / 600 秒间隔；一轮完成后才开始计时，不叠加检测。
• 出口 IP、trace 地区、HTTPS 连通性、延迟；手动正常基准；异常连续两次提醒，恢复连续两次确认。
• 国内、海外、Cloudflare 三个参考出口；只供分流对照，不参与 AI 基准告警。
• 中文归属地、ASN、运营商、时区、VPN / Proxy / Tor / 机房 / 移动网络情报标签。
• 本机活动网络接口的 IPv6 支持和地址类别；不修改 IPv6、DNS、系统代理或 TUN。
• 浏览器环境检测入口：在你实际登录 Claude 的浏览器访问 Net.Coffee。
• Mihomo 活动链路观察、固定出口保护脚本导出和规则核验。

登录前重点检查
保持落地 IP 干净；关闭 IPv6；DNS 正常无泄露；关闭 WebRTC。
这些是检查提醒，并不表示工具已经验证通过。
本工具的请求可能与采用独立代理 / 按进程分流的浏览器不同；trace 可用不代表账号、模型 API、平台资格或风控可用。情报库“未标记”不代表住宅 IP、安全或平台认可。归属地无法确定街道或门牌。

Mihomo 接入
设置中点击“查找管道”，确认是当前使用的代理实例后保存。
常见路径：\\.\pipe\verge-mihomo，新版本可能有带用户标识的名称。
管道无权限或代理未提供该接口时，链路和出口锁定不可用，但基础出口检测仍可使用。
无需打开 TCP 控制端口；应用不会修改代理配置、读取节点密码、切换节点或重启代理。
链路观察需同时捕获 Claude 网页和 API 的活动连接；未捕获显示未知，不保证已观察全部流量。

固定出口保护
1. 在“出口锁定”读取固定节点，选择落地节点及 Claude / OpenAI 范围。
2. 导出 .js。文件只包含节点名称、类型、前置关系及域名，不含认证密码。节点名仍可能含个人信息，不要随意公开。
3. 先备份 Clash Verge Rev 当前订阅扩展脚本，将完整 BEGIN / END 区块追加到末尾。更新时替换旧区块，不重复叠加，不覆盖原链路脚本。
4. 保存、应用订阅并保持规则模式，重新打开 AI 页面 / 客户端以建立新连接。
5. 在工具中“检查生效情况”。结果仅代表核验时刻配置，不是持续全流量保证。
6. 撤销时只移除 BEGIN / END 区块并重新应用订阅。

规则直接指向固定落地节点，每条后面紧跟 REJECT，防止不支持 UDP 的节点回落其他规则。节点缺失、类型或前置关系改变时拒绝。
OpenAI 范围包括 ChatGPT、OpenAI API 和 Codex。
只约束匹配域名且经过 Mihomo 规则模式的新连接。不是系统级断网开关；绕过代理的 DNS / WebRTC / IPv6、已有连接、未列出域名和同名节点背后的 IP 变化不在保护范围。
导出文件不代表已经生效；必须由你手动导入、应用和核验。工具退出不影响已被代理加载的规则。

隐私与本地数据
检测请求访问 claude.ai、api.anthropic.com、chatgpt.com、ip.3322.net、checkip.amazonaws.com、www.cloudflare.com；各来源正常接收请求出口 IP。
默认启用归属地 / 情报查询，会把探测 IP 发往 ipwho.is 和 api.ipquery.io，可在设置关闭；成功与失败均缓存 / 冷却 15 分钟。
浏览器检测网页仅点击时访问：https://ip.net.coffee/claude/
本地设置、基准、最近 1,440 次样本和 500 条事件：
%LOCALAPPDATA%\AIExitWatch\state.json
不云同步，不包含在发行包；通知只显示摘要。数据文件损坏时保留原件并提示，不静默覆盖。
退出应用后可备份数据目录。换电脑需自行确认新基准；不要把个人 state.json 或代理配置一起分享。
休眠、退出期间不检测；Windows 勿扰模式、共享屏幕、通知设置可能隐藏横幅。

卸载
先关闭登录启动并保存，再从托盘退出，删除解压目录即可。
本地数据独立保留；确认不再需要后自行删除上述数据目录。
