# 平台验证边界

macOS 原生界面已在开发设备上使用并进行过图标、通知、出口检测和布局验证。Windows 核心经过可移植测试与交叉编译；Windows 桌面交互仍属于试用范围。

自动检查覆盖：

- Swift 与 .NET 的出口解析、基准有效性、两次异常 / 恢复确认、数据未知语义、存储及保护规则。
- 实际生成的 JavaScript 保留原脚本和原配置，节点缺失 / 重名 / 前置改变时拒绝。
- macOS arm64 + x86_64 通用包与 Windows x64 自包含包构建。
- Windows 命名管道 HTTP 测试夹具，以及新建进程的短时启动检查。

自动检查不代表：朋友电脑的代理路由、Mihomo 真实管道权限、通知横幅、休眠恢复、开机启动或高 DPI 界面均已通过。

曾在独立 Mihomo 回环测试中验证固定两跳 TCP、节点断开拒绝、缺失节点拒绝和 UDP 防回落；移除 REJECT 的对照会绕出。一次测试在正常 TCP 连接断言处失败，诊断后的复测通过，首次失败原因未确认。该集成测试需要用户另外提供 Mihomo 可执行文件，普通 CI 不自动安装代理内核。

首次公开版本整体标为预发布版本。发现桌面兼容问题时，请提供版本、系统、缩放比例和脱敏复现步骤。
