- Mihomo 只读链路观察、固定出口保护脚本导出与规则核验。
- 加入隐私说明、贡献指南、安全报告入口、双平台自动测试与构建。

下载同页对应系统的 ZIP，并用 SHA256SUMS.txt 核对。源码压缩包不是可执行安装包。安装方法见 README。

从此前私下分享的 macOS 版本升级时，公开版使用新的应用标识，通知权限和登录启动需要重新设置；检测数据目录保持一致。先关闭旧版登录启动并退出，再安装新版，避免两个实例同时写入本地历史。公开发行包不带任何人的检测数据或代理配置。

保护脚本导出不等于生效；必须手动导入支持的代理软件并核验。工具不保证账号资格或平台风控结果。
