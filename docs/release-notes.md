# v0.3.2 · macOS 软路由链路提示修复

本次仅发布 macOS 安装包，支持 macOS 13+、Apple Silicon 与 Intel，继续标记为预发布版。Windows 用户请继续使用 [v0.3.1](https://github.com/52216108/ai-exit-watch/releases/tag/v0.3.1)。

- 使用软路由或路由器代理时，链路不可观测显示为普通说明，具体原因可按需展开；未启用链路观察时不再提示本地 socket 缺失。
- 出口 IP 检测、基准确认与 IP 变化告警不依赖链路观察，软路由用户可保持关闭。
- 包含自 v0.3.1 以来的 macOS 修复：仅对相对手动基准的出口 IP 变化告警；检测失败不触发新告警，也不解除已有 IP 变化告警。
- 改进本机 Mihomo 活动连接采样，并修复托盘弹窗的透明留白与内容高度同步。

下载本页的 `AI-Exit-Watch-0.3.2-macOS-universal.zip`，用 `SHA256SUMS.txt` 核对，解压后退出旧版，再将应用拖入“应用程序”替换。源码压缩包不是可运行安装包。本次升级保持应用标识和本地数据目录不变。

安装包使用 ad-hoc 签名，未做 Developer ID 签名或公证。构建、自动测试和界面渲染验证不等于真实软路由环境验收；本次未完成该环境实测。工具不保证账号资格、模型访问或平台风控结果。

- macOS 13+：Apple Silicon / Intel 通用包，ad-hoc 签名，无 Developer ID 签名或公证。
