# README 界面预览

这些 PNG 由当前 macOS 的 `Dashboard`、`ExitComparisonView` 直接离线渲染，不是实时网络检测截图，也不展示 Windows 界面。

## 脱敏方式

- IP 仅使用文档示例网段中的 `192.0.2.30`、`198.51.100.20` 和 `203.0.113.10`。
- 国家、地区、运营商、ASN、节点名称、延迟、时间与告警均为预设展示数据，不从真实网络结果转换。
- 不读取本机检测记录、代理配置、socket、用户名或通知权限，不发起网络探测。
- 每张图片内保留“示例数据”标识，避免被当作实际 IP 归属地或安全检测结论。
- 渲染入口和无副作用模型全部位于 `IS_DEVTOOLS` 编译守卫内，独立于应用 target，不进入安装包的可执行程序。

## 重新生成

在 macOS 上，从仓库根目录运行：

```sh
bash scripts/render-readme.sh
```

需要 Xcode / Swift。生成后逐张检查文本、裁切和布局，确认图片中没有真实 IP、节点名、本机路径或账号信息后再提交。
